# Driftseed Isle for iPhone and iPad

`ios/Driftseed.xcodeproj` is a small native app that runs the game full screen in a WKWebView. The whole game ships inside the app. It loads nothing from the internet, so it works offline and meets the App Store rule that an app's code must be in its bundle.

```
ios/
  Driftseed.xcodeproj         open this in Xcode
  Driftseed/
    AppDelegate.swift         app start-up; sound follows the silent switch and mixes with the player's music
    SceneDelegate.swift       the window; flushes the save to disk when the app goes to the background
    GameViewController.swift  the full-screen web view, plus the bridge: save backup, haptics, prompt() dialogs, links out
    BundleSchemeHandler.swift serves Web/ at driftseed://app/ (a real origin, so localStorage is stable)
    SaveStore.swift           a native copy of the save (Application Support/Saves), restored if WebKit ever clears it
    Web/                      the game: index.html (GENERATED by `npm run ios`), three.min.js, fonts/ (+ licences)
    Assets.xcassets           app icon (1024 px, from ios/art/AppIcon.svg), launch colour, accent colour
    Info.plist                portrait on iPhone, every way up on iPad, status bar hidden, no encryption
    PrivacyInfo.xcprivacy     privacy manifest: no tracking, nothing collected
  AppStore/                   listing copy, privacy policy, review notes, screenshots
  art/AppIcon.svg             icon source
```

## Keeping the app's copy of the game current

`ios/Driftseed/Web/index.html` is built from `src/`, like the web `index.html`. After you change the game:

```
npm run ios        # src/ → ios/Driftseed/Web/index.html (offline: local three.js and fonts, characters embedded)
npm run ios:check  # CI: is the app's copy up to date?
npm run ios:icon   # re-render the app icon from ios/art/AppIcon.svg (needs Playwright)
```

The built page is committed, so the Xcode project builds on a Mac without Node.

## First run on your Mac

1. Install Xcode 16 or newer from the Mac App Store.
2. Open `ios/Driftseed.xcodeproj`.
3. Select the **Driftseed** target and open **Signing & Capabilities**:
   - Set **Team** to your Apple Developer account. You need the paid Apple Developer Program ($99/year) to publish.
   - Change **Bundle Identifier** from `com.example.driftseed` to one you own, such as `com.yourname.driftseed`. It can't be changed after the app is live.
4. Choose an iPhone simulator, or your own iPhone plugged in, and press **Run** (⌘R).

Test on a real device before you submit, not just the simulator. The simulator draws WebGL in software, so it's slower and doesn't reflect real performance. For debugging, Debug builds can be inspected from Safari on the Mac: **Develop › [your iPhone] › Driftseed**.

## Submitting to the App Store

1. **Create the app record.** In [App Store Connect](https://appstoreconnect.apple.com), go to **Apps › + › New App**:
   - Platform: iOS.
   - Name: "Driftseed Isle", or another name if that one is taken.
   - Bundle ID: the one you set in Xcode.
   - SKU: anything, such as `driftseed-1`.
2. **Archive and upload.**
   1. In Xcode, set the run destination to **Any iOS Device (arm64)**.
   2. Choose **Product › Archive**.
   3. When the Organizer opens, click **Distribute App › App Store Connect › Upload**.
   4. Raise **Build** (`CURRENT_PROJECT_VERSION`) for every upload. Raise **Version** (`MARKETING_VERSION`) for every release.
3. **Fill in the listing.** Use [AppStore/metadata.md](AppStore/metadata.md) for the subtitle, description, keywords, category and age rating.
4. **Add screenshots.** Use the ones in `AppStore/screenshots/`:
   - `iphone-6.9/` (1290×2796) goes in the 6.9" iPhone slot.
   - `ipad-13/` (2048×2732) goes in the 13" iPad slot.
   They're real captures of the game. Retake them on a device any time; App Store Connect scales them down for smaller displays.
5. **Set up privacy.**
   - App Privacy: answer **Data Not Collected**.
   - Privacy Policy URL: required for every app. Host [AppStore/privacy-policy.md](AppStore/privacy-policy.md) anywhere public (GitHub Pages, a Notion page or your own site) and paste its link.
   - Support URL: also required, and can point to the same site.
6. **Write the review notes.** Paste the notes from [metadata.md](AppStore/metadata.md#notes-for-app-review). They explain that the game is fully bundled and offline, which pre-empts questions under guideline 4.2 (minimum functionality) and 2.5.2 (downloaded code).
7. **Submit for review.** Choose the build, then **Add for Review**.

## What's different from the web version

- **Friends (visits, likes, leaderboards) is hidden.** It runs on the claude.ai artifact database, which isn't available inside the app. The button only appears when that service is present, so nothing in the game changes. Bringing it to iOS would need its own backend, such as Game Center for leaderboards plus CloudKit or your own server for visits.
- **Saves are stored twice.** The game saves to `localStorage` as on the web. The app also mirrors every save to `Application Support/Saves/localStorage.json`, which is included in iCloud and device backups. On launch it puts back any save slot WebKit has cleared. After an in-game reset it doesn't, so a reset stays a reset.
- **Haptics.** The game's small vibration cues (`navigator.vibrate`, which iOS lacks) play as light, medium or heavy taps.
- **Rename prompts** (naming an animal) appear as native alert dialogs.

## Before you ship: a checklist

- [ ] Bundle identifier and team set; the app runs on a real iPhone.
- [ ] Play from a fresh install through landfall, planting the driftseed, and a day or two. Background and relaunch the app and check the save comes back.
- [ ] Try an iPad, or mark the app iPhone-only. To do that, set **Targeted Device Family** to `iPhone` (build setting `TARGETED_DEVICE_FAMILY = 1`) and delete the `ipad-13` screenshots. The HUD is sized for phones, so it looks small on a 13" iPad.
- [ ] `npm run ios:check` passes, so the app has the latest game.
- [ ] The app icon is one you're happy with. To change it, edit `ios/art/AppIcon.svg` and run `npm run ios:icon`, or drop your own 1024×1024 PNG with no transparency into `Assets.xcassets/AppIcon.appiconset/AppIcon.png`.
- [ ] Privacy policy and support URLs are live.
- [ ] The developer menu (tap the level badge) is still in the game. It includes free shells, time skip and Showcase farm. App Review doesn't object to it, but you may want to hide it before release.
